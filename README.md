# Traffic Forecast

Traffic Forecast is a full-stack application that predicts traffic congestion using AI models and visualizes the results on an interactive dashboard.

## Features
- **Backend**: FastAPI for AI model inference and REST API.
- **Frontend**: React + Tailwind for data visualization.
- **Infrastructure**: Docker, Nginx, Kubernetes for deployment.

## How to Run
1. Clone the repository.
2. Use `docker-compose up` to start the services.
3. Access the frontend at `http://localhost` and the backend API at `http://localhost/api`.
